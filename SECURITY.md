## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please report it responsibly rather than opening a public GitHub issue.

### How to Report

* **Private Disclosure:** Please report vulnerabilities via [GitHub's Private Vulnerability Reporting] *`author@maxwilder.win`*.
* **Details to Include:** Please provide as much detail as possible to help us reproduce and fix the issue quickly:
  * Type of vulnerability (e.g., SQL injection, XSS, remote code execution).
  * Full paths or source file names affected.
  * Step-by-step instructions or proof-of-concept code to reproduce the issue.

### What to Expect

* **Acknowledgment:** You can expect to receive an initial acknowledgment of your report within **48 hours**.
* **Updates:** We will provide regular status updates as we investigate and develop a fix (typically every 5 to 7 days).
* **Disclosure & Resolution:** Once a fix is verified and released, we will coordinate a public advisory disclosure, giving appropriate credit to you as the reporter if you wish to be recognized.

Thank you for helping keep our project and users safe!
